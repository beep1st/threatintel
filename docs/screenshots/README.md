# Adding project screenshots

Upload your screenshots to this folder using these names:

| Image | README dropdown |
| --- | --- |
| `dashboard.png` | Dashboard |
| `threat-library.png` | Threat library |
| `article-analysis.png` | Article analysis |
| `threat-actors.png` | Threat actors |
| `mitre-attack.png` | MITRE ATT&CK |
| `groups-and-tools.png` | Groups and tools |
| `actor-matching.png` | Actor matching |
| `chatbot.png` | Chatbot |

1. Add an image here, either locally or with GitHub's **Add file - Upload files** action.
2. Edit the [main README](../../README.md) and find the matching `<details>` section.
3. Remove its *Screenshot coming soon.* line.
4. Remove the surrounding HTML comment (`<!-- Replace the placeholder above with:` and `-->`) while keeping the `![description](docs/screenshots/filename.png)` line.
5. Save and commit the change. The image will appear inside the expandable section.

Use the same filename capitalization shown above. For JPG or other formats, update the image link accordingly. Capture readable screenshots and hide API keys, private data, and personal information before uploading.
